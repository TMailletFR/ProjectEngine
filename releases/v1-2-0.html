PROJECTENGINE RELEASE · v1.2.0

Faster Gantt Rendering for Large Excel Project Schedules

Unified Gantt update pipeline, differential rendering, one SVG dependency layer and improved large-project responsiveness.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

One Gantt pipeline

Planning updates, TEST, SCENARIO, RESET, LOCK, critical-path modes, scale changes and drag operations converge through the same rendering pipeline.

Reuse rather than redraw

Existing valid task graphics can be retained or selectively updated instead of deleting every Excel Shape. This improves unchanged and incremental rendering scenarios while full rebuilds remain necessary for some changes.

A single dependency layer

Dependency links are consolidated into one generated SVG layer instead of thousands of individual Excel line shapes.

Large-project validation

The release was validated on standard schedules and a 1,200-task test configuration. Specific benchmark improvements were reported for targeted calculation stages, not as a universal speed-up.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
