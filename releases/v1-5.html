PROJECTENGINE RELEASE · v1.5

Financial Project Controls and Multi-Project Budgets in Excel

New Finance module for budgets, dated expenses, cost forecasts and multi-project reporting, plus Dashboard, S-Curve and project migration improvements.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine v1.5 expands its open-source Excel scheduling platform with financial project controls. Plan task-level budgets, record dated expenses and credits, estimate remaining costs, and monitor monthly and cumulative financial performance without a separate application.

New Finance and Finance Summary worksheets

Manage budgets, actual expenses, Estimate to Complete (ETC), Estimate at Completion (EAC) and cost variance against activities linked to the existing Work Breakdown Structure. Review monthly and cumulative planned versus actual expenditure with separate, explicit Finance refreshes.

Multi-project cost control without double-counting

Manage financial projects independently or connect them through copied and shared records. The Global view consolidates genuinely independent costs while counting shared financial records once.

Dated expense journal and familiar Excel editing

Record expenditure, credits and future-dated transactions using a native Excel input table with filtering, sorting, copy/paste and a controlled Confirm/Cancel workflow. Future expenses stay in the journal without appearing prematurely in actual-spend charts.

Flexible spending profiles and financial snapshots

Distribute planned budgets at an activity’s START, at its END, or LINEARly over its duration. The dedicated Extract Finance action captures reporting information without changing the underlying financial records.

Better migration and project continuity

The new workbook schema supports persistent multi-project Finance data. Compatible project imports retain supported financial records and better preserve editable WBS formatting and supported column widths. Import replaces destination project data; always back it up first.

Dashboard, S-Curve and reset reliability

Dashboard summary progress and coloring are more representative, snapshot creation is better protected, S-Curve baseline resolution handles additional valid cases, and Full Reset removes more project-specific leftovers before starting again.

Compatibility and validation

Targeted Excel for Windows testing covered normal schedules, approximately 1,200-activity workloads, finance/migration scenarios, save/reopen and bilingual interfaces. Not every Excel 32-bit, LTSC/perpetual, DPI or crash-recovery configuration has been certified.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
