PROJECTENGINE RELEASE · v1.1.0

Simulate Project Delays and Recalculate Critical Path in Excel

TEST and Drag & Drop now recalculate critical path, longest path and float; Reset restores the prior calculated view.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

Live scheduling consequences during simulation

Moving a Gantt activity can update successor dates, total/free float, critical/longest path indicators and project finish in the non-destructive TEST state.

A dedicated Reset action

Reset clears active simulation assumptions and restores the last calculated normal schedule without unnecessary Core recalculation.

More reliable user interactions

The release improved drag behavior after Detail/Summary transitions, manual Gantt column resizing and consistency of constraints and path controls.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
