PROJECTENGINE RELEASE · v1.0.0

ProjectEngine 1.0: Open-Source Scheduling Engine for Excel

First stable baseline integrating dependency scheduling, critical-path analytics, simulation, Gantt, Dashboard and S-Curves.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

Dependency-driven scheduling

The stable engine supports FS, SS and FF links, lags, calendars, milestones, Level of Effort, input priorities and automatic propagation through a project network.

Project controls analytics

Critical Path, Longest Path, Total Float, Free Float, Driving Logic, deadlines and baseline/forecast variance are calculated from the planning model.

Simulation and reporting

TEST, SCENARIO, LOCK, interactive Gantt, Dashboard and S-Curves share the same underlying scheduling engine rather than separate date-calculation implementations.

Documented and maintainable

The first stable release established documented architecture, owner boundaries and regression harnesses for future versions.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
