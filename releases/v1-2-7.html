PROJECTENGINE RELEASE · v1.2.7

Excel Gantt Stability When a Schedule Has No Dependencies

Fixes Full Update, Forced Planning Update and Gantt refresh in valid schedules with no predecessors.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

Schedules without predecessors are valid

The Gantt dependency layer now handles a project with zero dependency links rather than interpreting the absence of links as a missing dependency model.

Reliable Full and Forced Updates

The internal dependency-table writer now handles empty Excel table data bodies correctly. The fix covers adding the first predecessor, removing the last one, and alternating between linked and unlinked schedules.

Focused maintenance release

No new scheduling feature or workbook structure change was introduced. Tests covered refresh, reset, save/reopen and representative large schedules.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
