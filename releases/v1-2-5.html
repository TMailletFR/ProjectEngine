PROJECTENGINE RELEASE · v1.2.5

Critical Path and Gantt Dependency Fixes in Excel

Improved predecessor updates, summary SS/FF analytics, Longest Path REX and dependency-arrow reliability.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

Dependency changes update incrementally

Changes in link types, deleted predecessors and obsolete dependency graphics are reconciled without forcing a full planning update in the covered cases.

Summary-task SS and FF semantics

The analytics network consistently interprets summary Start-to-Start using the earliest summary start and summary Finish-to-Finish using the latest summary finish, eliminating artificial negative Free Float in the affected cases.

Gantt arrows and geometry

Dependency graphics are kept visually aligned and visible in front of bars while retaining task interaction. Related improvements cover milestone FF terminations, column changes and saved-state reconciliation.

Reliable analytics and international formulas

Longest Path REX output was restored where valid. Managed WBS formulas use language-independent formula syntax to reduce failures on non-French Excel installations.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
