PROJECTENGINE RELEASE · v1.4

Learn Project Scheduling in Excel: Interactive Tutorial & Modern UI

A 29-step bilingual tutorial with Discovery and Practice modes, redesigned dialogs, smarter message windows and improved onboarding.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

Learn ProjectEngine with 29 guided steps

The interactive tutorial runs inside Excel and explains how to build a WBS, work with dependencies, read scheduling analytics and navigate Gantt, S-Curve and Dashboard views. The same tutorial is available in French and English.

Discovery and Practice modes

Discovery mode is a non-destructive tour that works even when the schedule is empty. Practice mode supports real task entry and normal planning commands. Blocking errors are handled by the existing scheduling diagnostics rather than a second tutorial-specific validation system.

A more accessible Excel interface

The ProjectEngine Ribbon now includes the Tutorial command. Welcome offers a discovery path alongside creating or importing a project. The three dialogs—Welcome, Planning Messages and Tutorial—have improved typography and modern buttons. Planning messages use more adaptive sizing without losing selectable text or scrolling.

Safer workflow and privacy improvements

The welcome screen returns after a cancelled import when appropriate. Import processing avoids persisting the source workbook’s absolute path and raw error descriptions unnecessarily. This is metadata hygiene, not a guarantee that an Excel file contains no personal or project information.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
