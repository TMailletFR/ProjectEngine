PROJECTENGINE RELEASE · v1.3

Excel Project Scheduling: New Ribbon, Project Import and Gantt Navigation

Embedded 18-command Ribbon, import of previous ProjectEngine projects, first-use welcome screen, better Gantt navigation and reduced redundant Excel writes.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

An integrated Ribbon for planning

ProjectEngine introduced a dedicated Excel Ribbon with 18 embedded commands. Planning updates, Gantt simulation, navigation, settings and reset actions are grouped contextually; no external add-in is required.

Bring an older ProjectEngine project forward

Import Previous Project transfers supported WBS inputs, dependencies, dates, constraints, settings, acknowledgements and historical Dashboard snapshots. The source is opened read-only and remains unchanged. The destination data is replaced, so back it up before import. Import does not automatically rerun calculations or transfer older Gantt graphics.

Navigate complex Gantt charts

Show Full Timeline offers a project overview, subject to Excel zoom limits. Go to Selected Task finds the rendered activity by Task ID without unexpectedly changing the Summary view.

Avoid unnecessary worksheet rebuilding

Full Update continues to recalculate the schedule and analytics completely, but can skip rewriting identical calculated output columns. Gantt rendering can reuse valid graphics and dependency routes where supported. Neither optimization implies every full rebuild is faster.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
