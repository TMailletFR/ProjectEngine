PROJECTENGINE RELEASE · v1.2.6

Localized Excel Project Planning: French, English and LTSC Support

Language-independent schemas for 81 visible columns, global date formats, Excel Notes fallback and S-Curve cache fix.

Official GitHub releaseDownload latest ProjectEngine

ProjectEngine is a free, open-source project scheduling and project controls engine that runs natively in Microsoft Excel. This update contributes the following changes to its dependency-driven planning workflows.

French and English visible table headers

A centralized, language-independent schema allows 81 visible columns across WBS, S-Curve, Constraints and Event History tables to switch between French and English without changing the scheduling logic.

Date display independent of language

Choose DMY, MDY or ISO date display for major workbook surfaces. Date values and scheduling calculations remain unchanged.

Compatibility with older Excel editions

When modern threaded comments are unavailable, WBS onboarding can fall back to classic Excel Notes. This compatibility path was validated in a controlled test; testing on all LTSC installations was not claimed.

More robust S-Curve caching

The S-Curve uses a compact hash-based persisted cache key to avoid Excel’s defined-name formula length limit and to avoid unnecessary chart source reassignment.

Using this release

Download the prepared .xlsm workbook from GitHub and enable macros only if you trust the source. When upgrading a working project, keep a backup. For the full original changelog and validated scope, consult the official GitHub release notes.
